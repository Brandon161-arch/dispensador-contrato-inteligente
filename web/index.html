03 · La regla

Tres pasos, cero sorpresas

La misma comprobación ocurre en la pantalla y dentro del contrato.

1

Eliges

La máquina muestra el precio y cuántas unidades quedan. El contrato guarda esos datos.

2

Pagas

El pago viaja con la compra. Si es menor al precio, todo se revierte y no pierdes nada.

3

Recibes

Si alcanza, baja el stock, se registra la venta y el cambio vuelve a tu saldo.

💡

La regla de oro: pago suficiente + stock disponible = entrega. Si algo falla, no se descuenta nada.

04 · El contrato

La regla vive en el código

Un contrato inteligente es un programa pequeño que se ejecuta igual para todos. Aquí guarda el menú, el stock y los precios, y decide cada compra sin un cajero de por medio.

  • El pago y el cambio se mueven en la misma transacción.
  • Solo la cuenta dueña puede reponer stock o retirar lo recaudado.
  • La entrega física ocurre en la máquina: el contrato no ve la bandeja.

Contrato: Sin desplegar · modo demo

DispensadorComida.sol comprar() 
function comprar(uint256 id) external payable
    returns (uint256 cambio)
{
    Producto storage p = _buscar(id);

    if (p.stock == 0) revert SinStock(id);
    if (msg.value < p.precio)
        revert PagoInsuficiente(msg.value, p.precio);

    cambio = msg.value - p.precio;
    p.stock -= 1;
    ventas += 1;

    emit Compra(msg.sender, id, p.nombre,
        p.precio, cambio, p.stock, ventas);

    if (cambio > 0) {
        (bool ok, ) = msg.sender.call{value: cambio}("");
        if (!ok) revert FalloAlEnviar(msg.sender, cambio);
    }
}
